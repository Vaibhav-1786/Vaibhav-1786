# Animation Notes

`assets/profile.gif` is the primary animated banner. It preserves the supplied Vaibhav Chauhan / Vaibhav-1786 artwork and adds subtle cinematic motion: orbit highlights, particle twinkles, a moving scanline, and gentle brightness breathing.

The animation is intentionally restrained so the banner remains professional and readable on GitHub and portfolio pages.

`assets/profile.png` is the high-quality static reference image.
`assets/profile.svg` is an editable vector-style source with the updated branding.
